================================================================================
GLOBAL SCOPE SHARING
================================================================================

Apps Script runs all .gs files in the same global scope. This means:

✅ CONFIG is accessible from all files
✅ Functions can call each other without imports
✅ No module system or require() needed
✅ All constants and variables are shared

Example:
  Main.gs can call:        gatherReportData() from DataGathering.gs
  DataGathering.gs can use: CONFIG from Config.gs
  ReportGeneration.gs can call: convertHeifToJpeg() from ImageProcessing.gs

This is a feature of Apps Script, not a limitation!
