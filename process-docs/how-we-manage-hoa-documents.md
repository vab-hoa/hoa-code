# How We Manage HOA Documents

Villas at the Boulders Association
For current and future board members
DRAFT for board review, 2026-10-31. Replaces the Document Organization Guide, HOA Board Drive Guide, and Working in Google Drive v1.0.

## The One Rule

Work happens in HOA Board Documents. What homeowners see comes from HOA Documents.

Think of HOA Board Documents as the workshop and HOA Documents as the front window. Drafts, working files, and board-private material stay in the workshop. Anything a homeowner should be able to read goes in the window, and the website points there.

## Where Things Live

The HOA has three shared Google Drives. You will see them under "Shared drives" in the left sidebar of Google Drive.

**HOA Board Documents** is the workshop. Only board members and the property manager can see it. It holds drafts, working versions of governing documents, budgets in progress, insurance files, contracts, owner issues, correspondence, meeting prep, and anything else that is board business. Some folders contain a shortcut marked with an arrow (→). The shortcut opens the matching folder in HOA Documents, so you can publish without switching drives.

**HOA Documents** is the window. Every owner and non-owner occupant can see it. It holds the final, approved versions of documents in a form homeowners can read. It is organized in folders:

- BRL Master Documents (Broadlands Master Association documents)
- Budgets (annual budgets, by year)
- Financials (monthly financial reports)
- Forms (current ARC application, planting application)
- Governing Documents (bylaws, covenants, ARC guidelines, articles)
- History (some history of the Villas at the Boulders)
- Insurance (the HOA insurance policy)
- Landscaping (documents from the LBC)
- Maps (plat documents, model map)
- Meetings (published board meeting minutes)
- Newsletters (newsletters, by year)
- Policies (all current HOA policies)
- Reserve Studies (reserve study reports)

Two files sit at the top level because they answer a homeowner's first two questions: **Directors and Officers** (who runs this place) and **Policy Directory** (what rules apply to me).

**HOA Website** is the public website, villasboulders.org. It is a navigation layer, not a document store. It points to files in HOA Documents. Its pages are built in Google Sites, and Google does not give us a way to edit Sites from outside, so website changes are made by hand.

## Words You Will See

If you think in Word terms, this table translates the Google Drive words.

| In Word | In Google Drive |
|---|---|
| A file on your computer | A file in a shared drive |
| "My Documents" or a network folder | A shared drive (belongs to the HOA, not to you) |
| Save As | Make a copy (File menu, then Make a copy) |
| Track Changes | Suggesting mode (the pencil icon at the top right) |
| Comments in the margin | Comments (select text, then Insert, then Comment) |
| Document versions | Version history (File menu, then Version history) |
| Email an attachment | Share the file, or send a link (see "Sharing" below) |

Two important points. First, a Google Doc is the same kind of thing as a Word document, except that it lives in the browser and saves itself as you type. Second, a file in a shared drive belongs to the HOA. If you leave the board, the files stay where they are.

## Creating a New Document

1. Decide which drive it belongs in. If homeowners should be able to read it when it is final, it starts in HOA Board Documents and its final version goes to HOA Documents. If it is board-only, it stays in HOA Board Documents.
2. Open the folder where it belongs. Click **+ New** and choose **Google Docs** to start from blank, or **File upload** to bring in a Word file you already have.
3. Name it clearly. Use the document's name followed by the date, such as "Snow Removal Policy 2026-10-31". Put dates in year-month-day order so the files sort correctly.
4. If you upload a Word file, you can keep it as a Word file, or convert it to a Google Doc (right-click, then Open with, then Google Docs). Convert it if you expect a lot of editing. Keep the original Word file as a record.
5. Share it with the people who need to work on it. Use the Share button, and make sure the person has Editor access if they will change it.

## Updating an Existing Document

Every updated document is one of two kinds of change. Choose the kind before you start, because it decides whether any website link needs to change.

**Kind 1: Replace the file in place.** Use this when the document is the same document, just with newer content. The website links keep working because the file keeps its identity.

- For a PDF already in HOA Documents: right-click the file, choose **Manage versions**, then **Upload new version**, and pick the new PDF. The file keeps its link.
- For a Google Doc: edit it directly. Its link stays the same.

**Kind 2: New file.** Use this only when the old file should stop being the document, for example when a bylaws amendment makes a new complete set, or when the file name would change in a way that matters to homeowners. A new file has a new link, so every page that points to the old file has to be updated (see the checklist below). If you are not sure which kind you have, ask the IT Officer before you upload.

Rule of thumb: if you delete a file and upload a new one, the link breaks. Use "Manage versions" instead.

**Making edits safely.** Use the Google Docs features below. The right one depends on what kind of change you are making.

- **Just edit** for fixing a typo, a date, or wording where nobody would object. This is the default. Do not use Suggesting mode for this, because a pile of unresolved suggestions makes a document harder to read, not easier.
- **Suggesting mode** (the pencil icon, then Suggesting) for changes someone might reasonably disagree with, such as a change to what a policy requires or permits. Suggestions show up in colored text, and each one is accepted or rejected. Someone has to review them.
- **Comments** (select text, then Insert, then Comment) for a question or a flag that does not change the text.
- **Version history** for a big change, such as restructuring a document or taking it in a new direction. Before you start, go to File, then Version history, then See version history, click the three dots next to the current version, and choose **Name this version**. Name it something like "Before simplification, 2026-10-31". Named versions are kept, and you can return to them later.

## Getting a Document to Homeowners

Homeowners read PDFs. They should not have to open Google Docs or Word files.

1. Finish the document and record the date the board approved it, inside the document.
2. Download it as a PDF: File, then Download, then PDF Document.
3. Open the matching folder in HOA Documents. You can get there from HOA Board Documents through the → shortcut.
4. Upload the PDF, or use Manage versions if you are replacing an existing PDF (see Kind 1 above).
5. Name the PDF with the document name and the approval date, such as "Snow Removal Policy (approved 2026-10-31).pdf". For newsletters, use the month and year, such as "January 2027 Newsletter.pdf".
6. Check sharing. Right-click the file, choose **Share**, and set General access to **Anyone with the link, Viewer**. This is required for website links to open without a login. See "Sharing" below.
7. If the document is new (Kind 2), update the website pages listed in the checklist below.

Files you upload into HOA Documents are visible to homeowners as soon as they are uploaded. Check the name and the content before you upload.

**What belongs in HOA Documents:** final PDFs. The exceptions are the History folder (video and transcripts from the oral history project) and the Maps folder (images and spreadsheets where needed for reference).

**What does not belong in HOA Documents:** drafts, working versions, Word or Excel source files for documents that already have a final PDF, superseded versions of governing documents (keep those in HOA Board Documents), and anything private to the board.

## Sharing

Sharing controls who can open a file.

- **Anyone with the link, Viewer** is the setting for every file in HOA Documents that the website links to. Anyone with the link can open it without signing in.
- **Restricted** means only people named on the file can open it. Do not use this for website links, because visitors will hit a sign-in wall.
- Files copied or moved within Drive do not always keep the expected sharing setting. After you upload, check it.
- Do not share individual files from HOA Board Documents with homeowners. If a homeowner needs something, put the final version in HOA Documents.

You cannot drag a file from one shared drive into the other. To put a copy in the other drive, right-click the file, choose **Make a copy**, and upload the copy there. Or download it and upload it.

## Policies

Policy source documents (the Word or Google Doc versions the board edits) live in HOA Board Documents, under Policies and Procedures, then Policy Source Documents, then the policy's own folder.

1. Draft the policy in that folder. Before the meeting where it will be voted on, make sure it is a Google Doc.
2. When the board approves it, record the approval date inside the document.
3. Download it as a PDF and upload it to HOA Documents, Policies, then the policy's folder, as "Policy Name (approved YYYY-MM-DD).pdf". Remove or replace the old PDF.
4. Update the Policy Directory so it shows the new approval date.
5. Check sharing on the uploaded file.

## Governing Documents and ARC Guidelines

- Working versions (Word or Google Doc) live in HOA Board Documents, under Governing Documents.
- Approved versions (PDF) go to HOA Documents, under Governing Documents.
- Old versions stay in HOA Board Documents. Do not put them in HOA Documents.
- ARC Design Guidelines working files are kept by year in HOA Board Documents, under Governing Documents, then ARC Design Guidelines.

## Newsletters

1. Write the newsletter as a Google Doc in HOA Board Documents, under Communications, then Newsletters, then the year and month.
2. Download it as a PDF.
3. In HOA Documents, open Newsletters and the year folder, and upload the PDF with the name "Month Year Newsletter.pdf".
4. Check sharing.
5. The website's Newsletters link points to the Newsletters folder, so no website change is needed.

## Website Edits

You only need to edit the website when you add a link, remove a link, or change where a link points. Replacing a file in place does not require a website change.

When you do edit the website, use the checklist above, and open each page after you save it to confirm the link works.

## Access and Permissions

- Board members are added as Content managers. You can upload, edit, move, and delete files, but you cannot change who else has access or change drive settings.
- Board access is through the "Board" group (board@villasboulders.org). The property manager has access through the "Manager" group.
- Homeowner access is through the "Owners" group (owners@villasboulders.org) and the "Non Owner Occupants" group (non-owner-occupants@villasboulders.org).
- To add someone, or to change access, contact the IT Officer. Do not share files directly with individuals.
- Access depends on the Google account that was added. If you have more than one Google account, make sure you are signed in with the right one.

## If Something Goes Wrong

- **Deleted by accident.** Items stay in the drive's Trash for 30 days. Only drive members can restore them. Tell the IT Officer right away.
- **Overwritten by accident.** Open the file, go to File, then Version history, and restore the version you want.
- **A website link is broken.** Check whether the file was deleted or re-uploaded. If so, either restore it from Trash or update the website links using the checklist.

## Why the Drive Is Organized This Way

Our records go back about 25 years. Some were lost when we changed management companies in 2024, and that loss is why we keep our own copies of the documents we need. The Keystone portal is run by our management company. Nightly, an automated script copies work orders, ARC requests, violations, and new minutes and financials from the portal into a spreadsheet called Keystone Cache, so we keep our own record even if the management arrangement changes. The Keystone Cache lives in HOA Board Documents.

Board members do not need to run or check that script.
